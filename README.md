# Food Sport Restaurante

Sitio web del restaurante **Food Sport** (parrilla y bar deportivo), hecho con Next.js.

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Deploy (GitHub Pages)

El sitio se publica automáticamente con GitHub Actions al hacer push a `main`.

- Workflow: `.github/workflows/deploy-github-pages.yml`
- URL: https://kyara2005.github.io/FoodSport/

En el repositorio: **Settings → Pages → Source: GitHub Actions**.
